Comment utiliser la carte

  1. Créez votre groupement (champ « Nouveau groupement ») : il est sélectionné automatiquement.
  2. Cliquez sur les communes pour les attribuer au groupement actif. Une commune déjà prise change automatiquement de main (pas de doublon).
  3. La gomme libère une commune ; le clic droit sur un groupement le renomme ; ✕ le supprime ; cliquez sur la pastille de couleur d'un groupement pour la changer (couleurs FI, en évitant les doublons).
  4. Limoux est découpée en 3 secteurs (République, Guynemer, Saint-Jean), d’après l’adresse des 3 GA limousois : chaque secteur s’attribue séparément.
  5. Carcassonne est partagée entre circonscriptions : seule sa partie en 3ᵉ circo est affichée (quartiers Saint-Jacques, Le Viguier, Grèzes, Salvaza).
  6. Tout est enregistré automatiquement dans votre navigateur. Le bouton « Partager par lien » copie un lien qui montre la carte telle que vous la voyez.
